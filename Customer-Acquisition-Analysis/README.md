# Customer Acquisition Analysis

SQL project focused on customer acquisition, order behavior, revenue analysis, and acquisition channel performance.

## Project Overview

This learning project demonstrates how SQL can be used to analyze customer and order data, evaluate acquisition channels, compare customer behavior, and identify revenue trends.

## Business Goal

The goal of this project was to analyze customer acquisition performance, understand order behavior, compare acquisition channels, and evaluate revenue dynamics over time.

## Tools & Skills

- SQL
- JOINs
- GROUP BY
- Aggregate functions
- Filtering
- Sorting
- Customer analysis
- Revenue analysis
- Acquisition channel analysis
- Business analysis
